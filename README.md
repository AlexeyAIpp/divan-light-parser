# Парсер освещения Divan.ru

Собирает информацию о товарах из раздела «Освещение»:
название, цену и ссылку.

Подходит для сбора данных о люстрах, светильниках,
настольных лампах, торшерах и бра.

---

## Возможности

- Сбор товаров со страниц каталога.
- Исключение повторных ссылок.
- Сохранение результата в CSV.

## Установка

Открой терминал в папке проекта и установи зависимости:

```bash
python -m pip install -r requirements.txt
```

## Запуск

Выполни команду в папке, где находится `scrapy.cfg`:

```bash
scrapy crawl divan_light -O lights.csv
```

## Результат

После завершения появится файл `lights.csv`:

| name | price | url |
|---|---|---|
| Название товара | Цена в рублях | Ссылка на товар |

> При повторном запуске файл `lights.csv` перезаписывается.

## Парсер освещения Divan.ru

Программа на Python для сбора товаров из раздела «Освещение» сайта Divan.ru.

Собирает название, цену и ссылку на каждый товар.

---

## Возможности

- Сбор данных о люстрах, светильниках, настольных лампах, торшерах и бра.
- Переход по страницам каталога.
- Исключение повторных записей с одинаковыми ссылками.
- Сохранение результата в CSV.

## Установка

Открой терминал в корневой папке проекта — там, где находится файл `scrapy.cfg`.

Установи зависимости:

```powershell
python -m pip install -r requirements.txt
```

## Запуск

В том же терминале выполни:

```powershell
python -m scrapy crawl divan_light -O lights.csv
```

Дождись завершения работы. В конце появится сообщение:

```text
Spider closed (finished)
```

## Результат

Данные сохраняются в файл `lights.csv` в корневой папке проекта.

| Столбец | Содержимое |
|---|---|
| `name` | Название товара |
| `price` | Цена в рублях |
| `url` | Полная ссылка на товар |

> Параметр `-O` перезаписывает файл при каждом запуске.

При проверке 5 ноября 2026 года программа собрала 116 записей
с трёх страниц каталога. Количество товаров может меняться.
